# RAP EMPIRE Android

This repository packages the existing RAP EMPIRE HTML game as an installable Android APK using Capacitor.

## Build

GitHub Actions builds the APK automatically after a push to `main` or `master`. It can also be started manually from **Actions → Build RAP EMPIRE APK → Run workflow**.

When the workflow finishes, download the `RAP-EMPIRE-APK` artifact from the run summary. The APK is a debug build for testing and direct installation.

## Project structure

- `www/index.html` — original game (renamed from `Index.html` so the entry point is lowercase)
- `www/*.png` — original title image and 48 rapper portraits
- `capacitor.config.json` — Capacitor app configuration
- `.github/workflows/build-android.yml` — automatic Android build

The Android platform folder is generated by the workflow and is intentionally not committed to this starter repository.
